# AI Capstone

This repository contains my AI-assisted development capstone.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)

### Setup

```bash
git clone https://github.com/naman1015/ai-capstone.git
cd ai-capstone
```

### Run

```bash
node src/index.js
```

- Node.js
- Git
- Claude Code
- JavaScript
